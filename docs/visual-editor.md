# ویرایشگر گردش (نمودار + فهرست)

نتیجه رکورد و طراحی دستی در یک صفحه دیده و ویرایش می‌شود:

- **نمودار گردش:** بوم شبیه Visio — درگ شکل‌ها، اتصال با پورت، زوم/پن، گروه‌بندی انتخاب
- **فهرست مراحل:** درخت گروه → مرحله، همگام با نمودار؛ کلیک یک ردیف همان گره را انتخاب می‌کند

## عملیات روی بوم

- کشیدن «گروه (حلقه)»، «مرحله»، «شرط» از جعبه ابزار
- چندانتخاب مراحل + **گروه‌بندی انتخاب** → گروه جدید و انتساب مراحل
- روی گروه: **منبع تکرار** (`None` / `DataSource` / `Elements` / `Loops`) و `MoveLoop` و اتصال به منبع داده
- یال‌ها: بعدی (بنفش)، موفقیت (سبز با Ctrl)، شکست (قرمز با Shift)، والد گروه (آبی‌چین با Alt)

ذخیره: `POST /Tasks/SaveGraph/{id}` و `PUT /api/tasks/{id}/graph`
