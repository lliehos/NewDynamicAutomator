# ویرایشگر گردش (نمودار + فهرست)

هدف: فرآیند با **گروه / حلقه / شرط**؛ مراحل همیشه داخل گروه.

## بوم اصلی

- شکل‌ها: شروع، **گروه (حلقه)**، **شرط**
- مرحله روی بوم ریشه انداخته نمی‌شود
- **دبل‌کلیک** روی گروه یا راست‌کلیک → «ویرایش مراحل»
- یال‌ها: بعدی، موفقیت (Ctrl+پورت)، شکست (Shift)، والد گروه (Alt)

## نمای درون‌گروه

- فهرست مراحل همان گروه، افزودن/حذف، inspector اکشن
- «بازگشت به نمودار»

## ویژگی‌های گروه

- `RepeatSourceType`: None / DataSource / Elements / Loops
- سلکتور المان‌ها وقتی Elements
- منبع داده وقتی DataSource — بارگذاری اکسل از پنل «منابع داده» (ستون‌ها key/title، سلول‌ها key/index/cellValue)
- MoveLoop

ذخیره: `POST /Tasks/SaveGraph/{id}` و `PUT /api/tasks/{id}/graph`
