# ویرایشگر گردش (نمودار + فهرست)

هدف: فرآیند با **گروه / حلقه / شرط**؛ مراحل همیشه داخل گروه (به‌جز اقدام‌های آزاد روی بوم در نسخه فعلی).

## بوم اصلی

- شکل‌ها: شروع، **گروه**، **شرط**، **اقدام**
- **دبل‌کلیک** روی گروه → طراح داخل گروه
- راست‌کلیک → مشخصات / تبدیل گروه↔اقدام (بر اساس قوانین فعلی)
- یال‌ها: بعدی، موفقیت، شکست
- عرض نود اقدام با عنوان کامل فیت می‌شود

## نمای درون‌گروه

- شروع تو‌در‌تو، اقدامات، شرط‌ها
- «بازگشت به نمودار»

## سلکتور (inspector)

هر فیلد سلکتور:

| کنترل | معنی |
|--------|------|
| سوئیچ سلکتور پویا | منبع/ستون + توکن `{مقدار پویا}` داخل CSS |
| تکس‌باکس سلکتور | مقدار CSS |
| ذخیره / خواندن از حافظه | JSON `DASEL:` (افزونه + localStorage) |
| زنجیره فریم (JSON) | زیر سلکتور — مسیر فریم تا المان |
| سوئیچ دارای اتریبیوت | `[name="value"]`؛ مقدار ثابت یا پویا از دیتاسورس |

## ویژگی‌های شروع / تکرار

- روی نود **شروع** (ریشه یا داخل گروه): None / Loops / Elements / DataSource
- منابع اکسل و دیتاسورس مادر روی شروع فرآیند

ذخیره: گراف در `GraphJson` (`Processes`) / کش localStorage؛ `PUT /api/tasks/{id}/canvas` روی سرور.
