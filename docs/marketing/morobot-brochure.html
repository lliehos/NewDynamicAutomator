مروبات (Morobot)

گروه نرم‌افزاری سوراس

تاریخچه نسل‌های نرم‌افزار اتوماسیون (محصولات مشابه)

Morobot در یک خط توسعهٔ شناخته‌شده در صنعت RPA و اتوماسیون وب قرار می‌گیرد — از ابزارهای دسکتاپ و Selenium تا پورتال ابری و افزونهٔ مرورگر. خلاصهٔ مسیر محصولات مشابه (قبل از و همراه با Morobot):

  • RPA کلاسیک (دسکتاپ + مرورگر از راه دور) الگوی رایج بازار: ربات روی Windows، کنترل UI یا WebDriver، دیتابیس رابطه‌ای برای مراحل — مشابه UiPath / Automation Anywhere در مقیاس SMB.
  • Dynamic Automator V2 (ویندوز) اپ دسکتاپ + Selenium؛ ذخیرهٔ درختی Group/Step/Condition در SQL؛ ضبط تعاملی روی مرورگر — پایهٔ مهاجرت داده به Morobot V3.
  • Morobot V3 (پورتال وب) ASP.NET Core + SQL Server؛ گراف فرآیند در Canvas (JSON)؛ بدون Selenium روی سرور؛ پلن، اشتراک، منابع Excel مستقل.
  • افزونه Chrome MV3 از سه افزونهٔ جدا (Recorder / Player / Selector) به Morobot Global + Smart Recorder اختیاری؛ اجرا روی تب واقعی کاربر.
  • Enterprise امروز استقرار on-prem یا Cloud؛ لایسنس امضاشده؛ برندینگ سازمان؛ migration خودکار DB پس از آپدیت.

مشکل مشتری

  • کارهای تکراری روی پورتals، ERP وب، و فرم‌های آنلاین
  • وابستگی به نیروی انسانی برای copy/paste و کلیک‌های روزانه
  • عدم شفافیت در نسخه فرآیند و خطاهای انسانی

راه‌حل Morobot

ضبط (Record)
کاربر روی سایت واقعی کار می‌کند؛ Morobot مراحل را می‌گیرد.
طراحی (Canvas)
ویرایشگر گرافیکی، شرط، حلقه، اتصال Excel.
اجرا (Play)
اجرای خودکار با داده‌های اکسل یا متغیر.
مدیریت
پلن، سقف کاربر، اشتراک فرآیند، لاگ.

امکانات کلیدی

  • پنل کاربر و پنل مدیر (Admin)
  • افزونه Morobot Global: ضبط + اجرا + سلکتور
  • Enterprise: لایسنس امضاشده، trial، برندینگ سازمان
  • SQL Server، استقرار Windows/Linux، IIS/nginx
  • چند زبان (فارسی / English)

مزایا برای سازمان
