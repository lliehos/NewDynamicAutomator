Morobot Vendor Kit
==================

1. docs/vendor-ops-guide.md را بخوانید (راهنمای کامل کارمند).
2. license-keys/morobot-private.pem را از مدیر امن دریافت کنید (یک بار genkeypair).
3. VendorStudio.exe یا LicenseTool برای sign و package.
4. BUILD-VENDOR-KIT.ps1 خروجی zip برای تحویل به تیم پشتیبانی می‌سازد.

نسخه kit: docs/doc-versions.json → vendorKit
